# Meds Addis — Design Context

Source of truth for every visual decision in this project. If a change cannot be
justified against this file, it does not belong in the UI.

> **Direction change, October 2026.** This file previously specified **Clinical
> Swiss**: zero radius, no shadows, hairline rules, near-monochrome, mono for all
> data. A supplied reference image (a futuristic pharmacy storefront) was then
> adopted as the target, and the project moved onto its language: rounded
> surfaces, soft shadows, a teal accent, photographic hero. That decision was
> deliberate and it reverses several of the choices below that were previously
> listed as *tells*. The reasoning is recorded under "Adopting a reference"
> further down, because the contradiction is real and deserves to be written
> down rather than quietly deleted.

## Users

**Two distinct audiences, one system.**

1. **Patients in Addis Ababa**, mostly on a mid-range Android phone over a
   mobile connection, often while unwell or caring for someone who is. They are
   not browsing — they are looking for a specific medicine, checking whether it
   is in stock, and trying to get it today. They need to trust that what arrives
   is genuine and correctly dispensed. Their patience for decoration is zero.

2. **Pharmacists and dispensary staff** on a desktop, working a queue of
   prescription reviews and fulfilment tasks. They need density, scannability
   and unambiguous state. They will use this screen a hundred times a day.

The job to be done is *certainty*: is this the right medicine, is it real, will
it arrive, is this prescription valid.

## Brand Personality

**Regulated. Precise. Unhurried.**

The voice is a pharmacist who has done this for twenty years: plain, exact,
never salesy, never alarming. It states facts and lets you decide. It does not
say "Oops!" and it does not say "Awesome!". It says what happened and what to do
next.

Emotional goal: the interface should feel like it is on your side and cannot be
rushed into an error. Calm authority, not friendliness.

The voice did not change with the visual direction, and it is now the main thing
holding the two audiences together. A friendlier surface is not a licence for
friendlier copy.

## Aesthetic Direction

**Reference-led storefront.** The visual language is taken from a supplied
reference design and followed rather than reinterpreted: a teal accent, fully
rounded pills for every control, soft elevation on every surface, a light page
with white cards, and a photographic hero.

The reference objects are still physical, but consumer-facing rather than
clinical: a well-designed pharmacy counter, a product box, a prescription slip,
a circular icon well with a line glyph in it.

### Concrete commitments

| Dimension | Decision |
|---|---|
| **Type** | Plus Jakarta Sans for everything. IBM Plex Mono survives in exactly two places — `.mono` (an error digest) and the `<samp>` element — because those hold something you would copy or compare. |
| **Colour** | Brand teal `--brand`, sampled from the reference at `#17a69a` and stored as `oklch(65% 0.111 186)` (resolves to `#14a599`). Amber `--signal` now means exactly two things: **prescription-only** and **low stock**. Green `--ok` sits at hue 152, deliberately separated from the brand's 186, so "in stock" never reads as "brand". |
| **Primary action** | Brand teal, as a fully rounded pill. Amber is not a button colour any more — a warning colour under the user's cursor is the one place it should never be. |
| **Depth** | Soft shadows on every raised surface. Shadow colours are their own tokens (`--shadow-color`, `--shadow-color-lg`) because `light-dark()` accepts colours only and a `box-shadow` cannot be wrapped in it. |
| **Radius** | A real scale: `--r-xs` 6, `--r-sm` 10, `--r` 14, `--r-lg` 20, `--r-xl` 28, `--r-full` 999. Controls are pills; cards are `--r-lg`; page-scale panels and media are `--r-xl`. |
| **Rhythm** | Section heading with a quiet "View all" link on the right, and a small brand-tinted label above it. Two label devices survive: `.eyebrow` (a brand dash plus a sentence-case label, e.g. "Staff workspace") and `.section-index` (a numbered one, e.g. "01 — Shop by category"). Both are sentence case. **No uppercase eyebrows** — the markup authors sentences and the CSS no longer shouts them. |
| **Layout** | A centred `--container` of 1240px. Not offset, not asymmetric. |
| **Motion** | Elevation and colour on hover, a 2px lift on cards. Nothing bounces. `prefers-reduced-motion` collapses all of it. |
| **Icons** | Hand-written inline SVG, one stroke weight, drawn on a 24-unit grid. Never emoji. |
| **Theme** | Light and dark, both first-class, via `light-dark()` with `color-scheme` and explicit `[data-theme]` overrides. |

### Anti-references

Things this must explicitly **not** look like:

- **A template with the text swapped out.** The failure mode now is not
  ugliness or over-decoration — it is a page where nothing was decided locally:
  placeholder-ish copy, six identical tiles with no reason for six, a
  "Trusted by 2M+ customers" claim that no one made.
- **A generic SaaS dashboard.** Frosted glass, gradient overlays, a coloured
  card for every metric, a chart that cycles nine hues and encodes nothing.
- **A wellness app.** Soft pastels, photography of smiling people, and the word
  "journey".
- **The reference copied literally.** The reference is a *storefront for a
  general pharmacy*. This is a licensed pharmacy with a prescription workflow,
  a dispensary queue and an order tracker. Borrowing its shapes is right;
  borrowing its content would be the actual mistake.

### Adopting a reference

The previous version of this file listed a set of "AI tells" and the project was
built to avoid all of them. Several of those traits are present in the adopted
reference: a saturated teal accent, rounded cards with soft shadows, repeated
identical tiles, a hero stat row.

The distinction that makes this defensible:

- **A reference is a specific artifact made by a person.** A generated interface
  is the *statistical average* of many such artifacts, which is why it
  undifferentiates. Following one design faithfully is a decision; landing on the
  mean of all designs is the absence of one.
- **The tells still apply to anything the reference does not cover.** The
  reference has no auth page, no dispensary queue, no order timeline, no empty
  state, no dashboard. Those screens inherit the *language* — radius, shadow,
  accent, type — but not a template, and the old rules about not inventing
  furniture for them still hold.

Where the two directions genuinely conflicted, the reference won and the old
rule was deleted rather than left in the file to contradict the code. That is
why this section exists: so the next person can see the reversal was a choice
with a reason, not drift.

### What still reads as generated, in either direction

1. The `create-next-app` default font stack.
2. Emoji standing in for icons.
3. Copy with no point of view — true, grammatical, and interchangeable.
4. A section that repeats the same rhythm five times because it had five things
   to say and one way to say them.
5. A stat that was never measured. If the number is not in the data, it does not
   go on the page.
6. A discount badge whose numbers do not agree with the price beside it.

## Design Principles

1. **Every colour must earn its place.** Amber appears only where the user's
   attention is genuinely required — a prescription-only line, or stock about to
   run out. It is not a button colour and it is not a focus ring.
2. **Elevation has to mean something.** A card is raised because it is a discrete
   thing you can act on. A raised box inside a raised box means nothing, which is
   why `.card .spec-list` and `.card .table-wrap` flatten themselves.
3. **The type is the design.** Hierarchy comes from scale, weight and space —
   not from uppercase, not from wide tracking, not from colour.
4. **Mono is for columns.** Anything a user might compare or copy — a reference
   number, a batch number, a digest — aligns in tabular figures. Nothing else is
   set in mono, and nothing set in mono is a sentence.
5. **Density is respect.** A pharmacist reviewing a queue should see twenty
   orders, not four large cards. The rounded language is not a licence to make
   the tool airy.
6. **State is stated, never implied.** Never rely on colour alone to carry
   meaning. Every status has a word next to it.
7. **Accessibility is structural.** 44px targets, 4.5:1 body contrast, visible
   focus, real buttons and forms. Not a checklist applied at the end.
